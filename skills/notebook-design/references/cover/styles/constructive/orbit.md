# 案例 · 回望之弧

v33 到 v34 的转折是先指定受光面、暗面和断续弧光的作用，再为这三个位置分别制作撕边、复写纸和干刷素材。封底小圆与跨脊长弧贯穿整个展开。v34 获得方向认可。v46 根据意见移除前封上扬金箔，封底小圆描金继续保留。

续作时从 INKA+ 项目根目录进入 CoverStudio/projects/wish/jackets/orbit。先用 python CoverStudio/studio.py --project CoverStudio/projects/wish/jackets/orbit handoff 读取实时版本和待处理意见。需要对照视觉沿革时再打开该工程的《构成风续作.md》或《原始提案.svg》。涉及具体编辑命令时查 CoverStudio/skill/cover-studio/SKILL.md。其他 SKU 独立选用材料、路径和字体。
