# 素材处理方法

从参考里挑一个产生可见差异的动作。固定裁切和位置，比较输入与结果，记录保留的像素、色阶或色带、变形方向、叠放顺序，并写明这一步解决了哪个构图问题。能复现的处理存成配方，复杂位图同时保留原材和带透明度的加工结果。

| 视觉作用 | 可试的处理 | 原寸检查 |
|---|---|---|
| 受光边缘 | 从撕纸或折面按明度取亮边，保留断口和纤维，局部弯曲 | 若读成等宽圆环，缩短一端或露出折角 |
| 暗面体积 | 从色纸取断边与擦痕，用渐变映射控制暗部，再与亮片交叠 | 主体和底灰粘连时分开调明度 |
| 断续外缘 | 提取干刷的半透明笔触，旋转、裁切，让痕迹沿运动方向消失 | 看颗粒在成品尺寸下是否糊成实线 |

同一构图可以换处理方式。在单素材预览里并排看原材与试样，接受的素材再合成。保留一张“原材 → 透明素材 → 完整展开”的对照，后续意见可以直接落到对应层。
