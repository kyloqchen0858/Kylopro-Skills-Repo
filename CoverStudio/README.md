# INKA+ 品牌设计工作台

双击本目录的「启动封面工坊.cmd」，或运行 `python studio.py serve --open`。使用 Python 3.10 或更新版本。默认服务在本机 http://127.0.0.1:8791，工作台读写 projects/wish。关闭启动窗口会退出该窗口启动的服务。

源码版首次启动时显示本机 SKU 列表，点击「新建 SKU」创建第一个产品。工程数据库、图片和导出文件保存在本机。

## 从产品工作流进入

首页列出本机 SKU，可以新建产品。选择 SKU 后读该产品的产品拆解，查看交付物、依赖、已完成数、剩余数、验收记录和下一动作。右上角可新建独立 SKU。参考用纸、封面工艺、内页结构、贴纸索引以及内页工艺分阶段记录。
在「封面设计」中阅读视觉稿、比较完整外封的结构方案。点选只记录偏好，用户确认后才开放制作。旧的正面图层实验从该页底部进入。接手时打开「跨对话交接记录」或运行 `python studio.py handoff`。原始产品说明保存在工程数据库。

## 前封图层编辑器

在右侧选中对象，在属性面板修改尺寸、位置、混合模式与不透明度，或在设计稿上直接拖动。图片可原位替换，原版本保存在左侧过程栏。在设计稿和单对象蒙版之间切换，使用画笔擦除、补回或指定另一个对象作为遮挡来源。渐隐方向沿对象本地纵轴。SAM2 点选支持左键选入、右键排除。每次计算完成会产生独立版本，供继续修边。

### 像素级纹理合成管线（右侧「素材与蒙版」与「全局质感层」）

- **渐变映射上色（Gradient Map）**：支持 2–3 色停靠点、预设色带、色标位置调节、反转与强度滑块；将黑白/灰度素材通过 SVG sRGB `<feColorMatrix>` + `<feComponentTransfer>` 重映射到目标色带。
- **有机边缘蒙版 + 细金边描边**：通过 `<feTurbulence>` + `<feDisplacementMap>` 仅置换蒙版边缘（保持内部素材清晰不扭曲），打碎规则裁切为自然海岸线/撕纸边缘，并可沿该不规则轮廓生成 1–2px 金属描边与金箔高光微闪。
- **文字底层线条避让**：在文字图层的「素材与蒙版」中启用，自动生成带羽化的反向 `<mask>` 挖空文字下方的矢量线条并保留背景纹理，替代纯白实心底块。
- **全局质感层**：位于画布最顶层的纸纹 / 胶片噪点 / 棉纸纤维 / 自定义贴图层（支持 `multiply` / `overlay` / `soft-light` 与不透明度调节），导出交接稿 `ART.svg` 时一并合成，`UV.svg` 与 `DEBOSS.svg` 自动排除。

左侧选择历史步骤后，可以跟该步骤的父版本并排比较。在历史步骤上修改会从它建立新分支。输入新概念会在当前工程里创建一个独立快照；想生成独立文件夹，可使用 skill 中的 init 命令。工作台有六种可视构图参考，通用概念的主体先用占位形表示，由当前 Agent 找图、生成或导入真实元素。

## 导出和迁移

默认 A5 前封成品 148 × 210 mm，四边各 6 mm 出血，文件画布 160 × 222 mm。工艺面板保存接收方版名及机器/RIP 信息。选中对象的「指定为局部 UV」会把对应形状纳入同尺寸的独立版，可在青色叠加和黑色单版间切换。

导出目录包含独立彩稿 ART.svg、UV.svg、叠加预览、工单和 Illustrator.jsx。图片内嵌。用 Illustrator 的「文件 → 脚本 → 其他脚本」运行包内脚本，可生成 ART.ai 和 UV.ai，在另一份测试文件中移动 UV 路径、保存重开并记录。交付乙方选 ART.ai、UV.ai 和工单；UV-edit-test.ai 仅用于验证。导出使用 RGB 设计色，接收方负责材料、色彩转换及目标机器的专色映射。默认提供单独的工艺版文件。

迁移时复制工作台目录和完整工程文件夹（包括 project.sqlite 和 assets），在另一台电脑运行同一命令。模型接入见 [Agent 操作规范](skill/cover-studio/SKILL.md)。可选点选分割读取 COVER_SAM_HOME 下的模型、vendor 和 .venv；本机默认使用已有的「本地对象分割」安装。核心画布、笔刷、历史和导出仅依赖 Python 标准库及浏览器。

## 验证

test_workflow.py 使用临时工程检查历史分支、版本冲突、锁定和导出的坐标系；浏览器测试执行新概念、三版比较、画笔、重新打开与独立 CLI 读回。运行 `python -m unittest discover -s . -p test_workflow.py`。浏览器测试使用 Playwright 和本机 Chrome，可通过 COVER_CHROME 指定浏览器。

愿望本是独立练习稿。UV 选在纸飞机上，印刷机、接收方参数和实物打样尚待确定。

## 对话与改稿
点击「开稿」填写概念、风格及配色，可附带参考图片并注明用途。编辑时可给整张封面或所选图层写修改意见，工程中保存待办和 Agent 的处理回复。点击「交给本机 Agent」会启动已登录的本机 Codex CLI 并把本条意见及所附参考图提供给该 Agent；仅保存意见时不会启动模型。其他 Agent 读取同一份工程的 discussion 即可接手。
「＋添加」打开元素选择器，可直接添加图片或文字。「删除所选图层」写入新版本，可回到之前的版本恢复。
